# 变更背景/目的

入住办理模块的“发起入住申请”需要从列表页跳转到独立的新界面办理，而不是停留在原有同页弹窗流程。当前前端已存在跳转路由，但目标页面文件缺失，导致无法进入新界面。

# 变更文件清单

- `YiSmartCloud-front/src/views/serve/checkIn/apply.vue`

# 关键改动说明

- 新增 `apply.vue` 独立页面，承接“发起入住申请”入口。
- 页面包含基础入住申请表单（老人信息、入住信息、备注）及校验规则。
- 接入 `addCheckIn` 提交接口，提交成功后提示并返回入住办理列表页。
- 补充页面底部“返回/提交”操作区域，满足从列表页进入、提交后返回的完整流程。

# 影响范围（接口、数据库、前端、兼容性）

- 接口：复用现有 `POST /serve/checkIn`，未新增后端接口。
- 数据库：无表结构变更。
- 前端：新增 `checkIn/apply.vue` 页面文件，修复“发起入住申请”跳转目标缺失问题。
- 兼容性：不影响已有列表查询、编辑、删除流程；仅补齐新增申请跳转页面。

# 验证方式（已执行/未执行及原因）

- 已执行：代码级静态检查（页面组件结构、路由目标文件存在性、接口调用路径）。
- 未执行：本地运行联调与浏览器手工点击验证（当前会话未启动前端开发服务）。
