# 变更背景/目的

入住办理模块要求“新增”跳转到独立页面，并且新增页面结构需按原型分区展示（基本信息、家属信息、入住配置、签约办理），不再使用简化录入界面。

# 变更文件清单

- `YiSmartCloud-front/src/views/serve/checkIn/apply.vue`
- `YiSmartCloud-front/src/views/serve/checkIn/index.vue`

# 关键改动说明

- 将 `apply.vue` 重构为分段式申请页，页面结构对齐原型：
  - 基本信息（含照片/身份证正反面上传）
  - 家属信息（可增删行的表格输入）
  - 入住配置（入住期限、费用期限、护理等级、床位及费用项）
  - 签约办理（合同名称、签约日期、丙方信息、合同上传）
  - 固定底部按钮（返回、提交、费用预览）
- 保留并强化“新增跳转到独立页面”的提交流程：提交调用 `addCheckIn` 后返回列表页。
- 修复 `checkIn/index.vue` 中 `addCheckIn` 未导入的潜在运行时问题，避免后续进入旧新增分支时报错。

# 影响范围（接口、数据库、前端、兼容性）

- 接口：仍使用 `POST /serve/checkIn` 提交基础入住信息；费用预览为前端计算。
- 数据库：无表结构变更。
- 前端：`入住办理 -> 发起入住申请` 的独立页面展示形态更新，交互更贴近原型。
- 兼容性：不影响列表查询/编辑/删除现有流程。

# 验证方式（已执行/未执行及原因）

- 已执行：静态检查（字段绑定、按钮跳转、提交链路、组件引用）。
- 已执行：`apply.vue` 与 `index.vue` 的 lints 检查，未发现新增告警。
- 未执行：浏览器端手工点击与后端联调（当前会话未启动前端开发服务）。
