# 个人中心页视觉对齐

## 变更背景/目的
- 用户提供“个人中心”目标截图，要求当前 `我的` 页面按参考图对齐布局与风格。

## 变更文件清单
- `YiSmartCloud-member-uniapp/pages/my/index.vue`

## 关键改动说明
- 重构顶部区域：
  - 橙色渐变头图背景
  - 右上胶囊（3点+圆圈）样式
  - 头像 + 昵称/立即登录文案
- 重构“我的订单”卡片：
  - 标题 + “查看全部”
  - 四状态入口（待支付、待执行、已执行、已完成）
- 重构菜单卡片：
  - 我的预约
  - 我的合同
  - 我的账单
  - 每行右侧箭头，行分割样式与截图一致
- 保留底部 `uni-footer`，维持与首页统一激活色风格。

## 影响范围
- 前端：`我的` 页面结构、样式、交互入口重排。
- 后端接口：无变更。

## 验证方式
- 已执行：lints 检查通过，无新增错误。
- 未执行：微信开发者工具截图级比对（需用户本地刷新确认）。
