# 变更背景/目的

入住办理模块原“新增”在列表页弹窗内完成，现需求为点击新增后跳转到独立办理页面，以承载更完整的入住申请信息录入。

# 变更文件清单

- `YiSmartCloud-front/src/views/serve/checkIn/index.vue`
- `YiSmartCloud-front/src/views/serve/checkIn/apply.vue`
- `YiSmartCloud-front/src/router/index.js`

# 关键改动说明

1. 将 `入住办理` 列表页新增按钮文案由“新增”改为“发起入住申请”。
2. 新增按钮点击行为由弹窗改为路由跳转：`/serve/checkIn-apply/index`。
3. 新增独立页面 `checkIn/apply.vue`，按业务分区提供基本信息、家属信息、入住配置、签约办理四块录入区域。
4. 新增隐藏动态路由 `CheckInApply`，并通过 `meta.activeMenu` 保持侧栏高亮在 `入住办理`。
5. 提交时将新增页核心字段映射为 `addCheckIn` 入参并提交，成功后返回入住办理列表。

# 影响范围（接口、数据库、前端、兼容性）

- 接口：沿用现有 `POST /serve/checkIn`，未新增后端接口。
- 数据库：无表结构变更。
- 前端：`入住办理`新增入口与交互路径变更，新增一个独立页面与隐藏路由。
- 兼容性：原“修改/删除/导出/查询”流程不受影响；新增从弹窗切换为页面跳转。

# 验证方式（已执行/未执行及原因）

- 已执行：读取并检查变更文件语法与依赖关系，确认路由、页面、按钮事件已串联。
- 已执行：针对改动文件读取 IDE lint 诊断，未发现本次新增页与路由代码引入的新 lint 问题。
- 未执行：未启动前端进行人工点击联调（当前会话未运行本地 dev server）。

## 补充变更（页面美化）

### 变更背景/目的

用户反馈新增页面视觉层次较弱，需提升页面可读性与操作区识别度，增强业务表单填写体验。

### 变更文件清单

- `YiSmartCloud-front/src/views/serve/checkIn/apply.vue`

### 关键改动说明

1. 新增页面头部信息区（标题 + 描述），提升页面语义与引导性。
2. 优化分区卡片视觉：圆角、阴影、边框、间距统一，提升层次感。
3. 调整步骤标题样式与数字圆点视觉，增强模块分组辨识度。
4. 家属信息区操作按钮右对齐，表格输入区更整洁。
5. 底部操作区改为粘性区域（sticky），长表单场景下返回/提交更易触达。
6. 增加表单标签、间距与部分响应式样式微调，改善中小屏显示效果。

### 影响范围（接口、数据库、前端、兼容性）

- 接口：无影响。
- 数据库：无影响。
- 前端：仅 `apply.vue` 样式与少量结构调整，业务提交流程不变。
- 兼容性：不改变字段定义和提交载荷，兼容既有后端接口。

### 验证方式（已执行/未执行及原因）
