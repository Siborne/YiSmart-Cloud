# 首页主题与 Hover 色对齐

## 变更背景/目的
- 根据用户提供截图对齐首页视觉与底部导航激活色（hover/active）。
- 优先让首页呈现与截图一致的橙色主题、咨询卡、快捷入口结构。

## 变更文件清单
- `YiSmartCloud-member-uniapp/pages/index/index.vue`
- `YiSmartCloud-member-uniapp/components/Foot/index.vue`

## 关键改动说明
- 首页样式重构为橙色主题头部：
  - 顶部橙色渐变区、品牌标题、右侧胶囊占位。
  - Banner 卡片、入驻咨询卡、预约双卡、四宫格快捷入口、热门房型区。
- 首页补充快捷跳转：
  - 预约、机构介绍、绑定家人、我的订单、我的账单。
- 底部 tab 激活色从蓝色改为橙色：
  - `#2f80ff` -> `#ff8455`，并提升激活态字重。

## 影响范围
- 前端视觉：首页整体风格与用户截图更接近。
- 导航交互：底部 tab 激活态颜色统一为橙色主题。
- 后端接口：无改动。

## 验证方式
- 已执行：IDE lints 检查通过，无新增报错。
- 未执行：微信开发者工具截图级视觉比对（需用户端实机/模拟器确认）。
