# 变更背景/目的

在协作过程中发现新建文件偶发使用 GB2312/GBK 等编码，导致中文显示异常和后续编辑风险。为避免编码不一致，新增统一规则要求文件编码必须为 UTF-8。

# 变更文件清单

- `.cursor/rules/file-encoding-utf8.mdc`

# 关键改动说明

1. 新增全局规则（`alwaysApply: true`），要求所有新建或修改文件统一使用 UTF-8 编码。
2. 明确禁止使用 GB2312、GBK、ANSI、Big5、UTF-16 等编码保存。
3. 增加乱码场景处理约束：先转 UTF-8 再继续修改，避免脏编码持续传播。
4. 补充批量生成/脚本输出文件场景也需确保 UTF-8。

# 影响范围（接口、数据库、前端、兼容性）

- 接口：无影响。
- 数据库：无影响。
- 前端：无直接功能改动，仅增加工程规范约束。
- 兼容性：提升跨环境编辑兼容性，减少中文乱码风险。

# 验证方式（已执行/未执行及原因）

- 已执行：检查规则文件 frontmatter 与内容格式，符合 `.mdc` 规则文件结构。
- 未执行：未进行自动化扫描全仓历史文件编码（本次仅新增规则，不做历史编码迁移）。
