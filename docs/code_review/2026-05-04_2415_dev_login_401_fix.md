# 调试登录 401 修复

## 变更背景/目的
- 登录页调试登录接口返回 401：`/serve/member/user/dev-login` 认证失败。
- 目标：避免登录接口被旧 token 干扰，并增强后端放行匹配。

## 变更文件清单
- `YiSmartCloud-member-uniapp/utils/request.js`
- `YiSmartCloud-background/YiSmartCloud-framework/src/main/java/org/FlyingSparrow/YiSmartCloud/framework/config/SecurityConfig.java`

## 关键改动说明
- 前端请求层：
  - 对 `notToLoginApiUrl`（含 `/serve/member/user/login`、`/serve/member/user/dev-login`）不再携带 `Authorization` 头。
  - 避免本地过期/无效 token 影响登录类接口。
- 后端安全配置：
  - 对 dev-login 增加更强匹配：
    - 字符串路径放行（含尾斜杠）
    - `POST` 方法显式放行（含尾斜杠）

## 影响范围
- 登录链路：微信登录、调试登录更稳定，不受历史 token 残留影响。
- 其它业务接口：仍按 token 鉴权。

## 验证方式
- 已执行：静态代码检查。
- 未执行：后端重启后接口回归验证（`dev-login` 需重启生效）。
