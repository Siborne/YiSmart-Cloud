# 入住登记列表页与产品 UI 对齐（仅前端展示收敛）

## 变更背景/目的

入住登记列表页功能与控件过多，与产品设计稿不一致。按产品稿仅保留：两项查询、一项主操作、八列表格与「查看」操作；其余在前端隐藏，不删后端能力。

## 变更文件清单

- `YiSmartCloud-front/src/views/serve/checkIn/index.vue`

## 关键改动说明

- 查询区仅保留「老人姓名」「老人身份证号」，按钮顺序为「重置」「搜索」；去掉日期、床位、护理等级、老人 ID、排序等筛选项。
- 工具栏仅保留「发起入住申请」，去掉修改/删除/导出及右侧 `right-toolbar`。
- 表格去掉多选、主键 ID、老人 ID、分开展示的起止时间列、状态、排序、备注等列；增加序号列；列名与产品对齐（如「护理等级」「老人身份证号」）；「入住期限」合并展示为 `开始日期 ~ 结束日期`；增加「创建时间」列。
- 操作列仅保留「查看」，点击后请求现有 `GET /serve/checkIn/{id}` 并以只读描述列表弹窗展示。

## 影响范围

- **前端**：入住登记列表交互与可见字段；需具备 `serve:checkIn:list`、`serve:checkIn:add`、`serve:checkIn:query` 权限方可完整使用列表、申请入口与查看。
- **接口/数据库**：无变更；后端编辑/删除/导出等仍可用接口或菜单其他入口（若存在）。

## 验证方式

- 未执行自动化测试；建议在浏览器打开入住登记列表，确认筛选项、按钮、列与「查看」弹窗与产品稿一致。
