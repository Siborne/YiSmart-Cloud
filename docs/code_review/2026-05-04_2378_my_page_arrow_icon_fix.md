# 个人页箭头显示修复（去除 &gt; 文本）

## 变更背景/目的
- 用户反馈个人中心页右侧出现 `&gt;` 文本样式，视觉不一致。
- 将文本箭头替换为图标箭头，统一页面风格。

## 变更文件清单
- `YiSmartCloud-member-uniapp/pages/my/index.vue`

## 关键改动说明
- `我的订单` 右侧“查看全部”由文本 `>` 改为图标箭头。
- `我的预约/我的合同/我的账单` 每行右侧箭头由文本 `>` 改为图标箭头。
- 使用现有静态资源 `/static/arrows.png` 并旋转 180 度作为右箭头，避免引入额外依赖。
- 新增箭头样式：
  - 常规箭头 `right-arrow`
  - 小号箭头 `right-arrow mini`

## 影响范围
- 前端：仅 `我的` 页面箭头视觉与交互提示更新。
- 接口与后端：无改动。

## 验证方式
- 已执行：lints 检查通过，无新增报错。
- 未执行：微信开发者工具端视觉回归确认（需用户刷新后观察右箭头显示）。
