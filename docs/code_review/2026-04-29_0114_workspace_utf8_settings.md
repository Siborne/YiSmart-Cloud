# 变更背景/目的

- 解决当前项目中新增文件可能被保存为 GB2312/GBK 的问题。
- 通过项目级编辑器配置统一默认保存编码为 UTF-8，降低编码回退风险。

# 变更文件清单

- `.vscode/settings.json`

# 关键改动说明

- 新增项目级 VS Code/Cursor 设置文件，显式设置：
  - `files.encoding = utf8`
  - `files.autoGuessEncoding = true`
  - `files.eol = \n`
- 该配置仅作用于当前工作区，不影响其他项目。

# 影响范围（接口、数据库、前端、兼容性）

- 接口：无直接影响。
- 数据库：无直接影响。
- 前端：无功能性改动，仅影响文件保存编码与换行策略。
- 兼容性：对团队协作更友好，可减少 Windows 环境下编码不一致导致的乱码问题。

# 验证方式（已执行/未执行及原因）

- 已执行：检查 `.vscode/settings.json` 已创建且包含 UTF-8 相关配置。
- 未执行：未启动额外脚本批量重编码；本次变更为后续新改文件的保存策略控制。
