# 调试登录手机号校验修复

## 变更背景/目的
- 用户反馈输入 11 位手机号仍提示“请输入11位手机号”。
- 排查发现前端正则误写为 `^1\\d{10}$`（多一层转义），导致匹配失败。

## 变更文件清单
- `YiSmartCloud-member-uniapp/pages/login/index.vue`

## 关键改动说明
- 修复手机号校验正则：
  - `^1\\d{10}$` -> `^1\d{10}$`
- 增加输入清洗：
  - `String(devPhone.value || '').replace(/\D/g, '')`
  - 自动剔除非数字字符，减少输入法或粘贴带来的干扰。

## 影响范围
- 前端登录页：开发调试登录手机号校验恢复正常。
- 后端：无改动。

## 验证方式
- 已执行：lints 检查通过。
- 未执行：小程序端手工输入 11 位手机号回归验证。
