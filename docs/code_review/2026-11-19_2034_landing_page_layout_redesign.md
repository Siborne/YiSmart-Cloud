# Landing 页整体布局重设计

## 背景 / 目标

- 在上一轮“移除 Emoji、改用 SVG Icon”的基础上，将 `docs/site/index.html` 从单列居中布局重设计为更偏产品化的分栏布局。
- 保持既有交互能力与多语言/主题/粒子背景/滚动动画逻辑不变。

## 变更文件清单

- `docs/site/index.html`

## 关键改动说明

- **Hero**：由单列居中改为左右分栏；左侧为标题/副标题/描述/CTA/技术栈徽章，右侧新增“管理控制台”玻璃拟态预览卡（含状态徽章、三组指标卡与柱状图占位），并补充悬浮指标卡。
- **功能特性**：改为“左栏 sticky 标题 + 右栏 2×2 卡片”的分栏布局。
- **技术架构**：改为“左栏 sticky 标题 + 右栏前后端双卡”的分栏布局。
- **快速开始**：改为“左栏 sticky 标题 + 右栏纵向终端卡片”，后端/前端启动步骤改为更紧凑的分栏网格。
- **产品形态**：标题区改为左对齐分栏，增加右侧辅助提示，图片保持全宽展示。
- **CTA / Footer**：视觉微调，结构与 i18n 键不变。

## 影响范围

- **前端**：仅影响静态 Landing 页 `docs/site/index.html`。
- **接口/数据库**：无影响。
- **兼容性**：多语言切换、明暗主题、移动端菜单、粒子背景与 `.feature-card` / `.tech-card` 滚动动画逻辑保留；所有交互元素 ID 与 `data-i18n` 键保持一致。

## 验证方式

- 已执行：Emoji 正则扫描，确认页面无 Emoji。
- 已执行：校验 65 个 `data-i18n` 键均存在于 `docs/site/js/main.js`。
- 已执行：校验标签闭合平衡（div/section/svg）及 `main.js` 依赖的交互元素 ID。
- 未执行：浏览器视觉预览（建议本地打开 `docs/site/index.html` 复核桌面/移动端与暗色模式表现）。
