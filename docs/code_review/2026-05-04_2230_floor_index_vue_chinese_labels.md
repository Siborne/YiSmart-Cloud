# 楼层管理页文案修复（floor/index.vue）

## 变更背景/目的

`YiSmartCloud-front/src/views/serve/floor/index.vue` 中大量界面文案为占位符（`???` 等），影响可读性与交付质量。本次将查询区、表格、弹窗、校验与提示信息统一为与项目内 `serve/room` 等页面一致的中文业务用语。

## 变更文件清单

- `YiSmartCloud-front/src/views/serve/floor/index.vue`

## 关键改动说明

- 查询表单：楼层编号、楼层名称、搜索/重置及占位提示。
- 工具栏与表格列：新增、修改、删除、导出；排序、状态、创建时间、操作。
- 弹窗：添加楼层 / 修改楼层标题；表单标签与占位；确定、取消按钮文案（与房间页「确 定」「取 消」风格一致）。
- `rules` 与 `proxy.$modal`：校验失败说明、未选数据警告、删除确认、成功提示（新增成功 / 修改成功 / 删除成功）。
- 微调 `label-width`，避免四字标签换行拥挤。

## 影响范围

- **前端**：仅楼层管理列表页展示与交互文案；无接口、权限标识变更。
- **数据库 / 后端**：无。
- **兼容性**：无行为逻辑变更（除文案外）。

## 验证方式

- **未执行**：未在本地启动 `npm run dev` 做视觉回归；建议在「楼层管理」菜单下打开页面确认表格与弹窗文案显示正常、UTF-8 无乱码。
