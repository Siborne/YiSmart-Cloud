开始使用

几分钟内启动

轻松搭建本地开发环境

☕

后端启动

# 1. 初始化数据库

mysql -u root -p < sql/ry_20250417.sql

# 2. 修改数据库配置

vim application-druid.yml

# 3. 构建并启动

cd YiSmartCloud-background

mvn clean install -DskipTests

mvn -pl admin spring-boot:run

默认端口 8080
💚

前端启动

# 1. 安装依赖

cd YiSmartCloud-front

npm install

# 2. 启动开发服务器

npm run dev

默认端口 80
API代理 /dev-api → 8080
